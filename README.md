# Spotify Music Insights Dashboard-Trends, Top-Artists, Listening Patterns
Power BI | Data Visualization Project

📌 Overview

This project is an interactive Spotify Music Insights Dashboard built in Power BI and Figma for design. It analyzes streaming patterns, top artists, most-played songs, and listening behavior using dynamic visuals and DAX-driven measures.

The goal is to transform raw Spotify data into meaningful insights that highlight audience preferences, music trends, and seasonal listening patterns.

🛠 Tools & Techniques

Power BI Desktop

Data Cleaning & Modeling in Power Query

DAX Measures for KPIs and trend analysis

Custom Visuals for artist/song ranking

Interactive Filters, Slicers & Navigation Buttons

📊 Key Dashboard Features
1. Artist & Song Insights
Top artists ranked by number of songs played Most-streamed tracks with popularity scores Artist-wise distribution and frequency

2. Popularity & Trend Analysis
Month-over-month popularity trendline Average popularity per album type Seasonal listening behavior

3. Content Type Breakdown
Songs split by album vs single Explicit vs non-explicit content comparison

4. Listening Behavior Metrics
Total distinct songs
Total number of artists
Average song duration
Monthly count of distinct songs played
